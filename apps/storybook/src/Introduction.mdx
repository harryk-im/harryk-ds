# Harryk 디자인 시스템 📖

반가워요! **Harryk 디자인 시스템**에 오신 것을 환영해요.

이 디자인 시스템은 일관성 있고 재사용 가능한 UI 컴포넌트들을 차근차근 모아두는 곳이에요. 개발 효율을 높이고, 사용자에게 더 나은 경험을 선물하는 것을 목표로 하고 있어요.

## 🏗️ 아키텍처

우리는 **모노레포** 구조를 사용하여 프로젝트를 깔끔하게 관리하고 있어요.

### 📦 Packages

각 패키지는 각자의 역할에 집중하고 있어요.

- **`@harryk-ds/ui`**: 버튼, 배지 같이 화면을 구성하는 가장 기본적인 UI 컴포넌트들이 담겨 있어요.
- **`@harryk-ds/motion`**: 페이드인 효과처럼 화면에 생동감을 불어넣는 애니메이션 컴포넌트들이 모여 있어요.

### 🏢 Apps

- **`@harryk-ds/storybook`**: 컴포넌트들을 직접 눈으로 확인하고 테스트해볼 수 있는 우리만의 놀이터예요.

### 🎯 설계 원칙

우리는 **중앙 집중형 스토리 관리** 방식을 따르고 있어요.

- **순수한 라이브러리**: 컴포넌트 패키지는 부가적인 설정 없이 본연의 기능에만 집중해요.
- **한곳에 모인 스토리**: 모든 스토리 파일은 `apps/storybook/src/stories`에서 효율적으로 관리해요.
- **최적화된 사용자 경험**: 불필요한 의존성을 줄여서 번들 크기를 최소한으로 유지해요.

## 🚀 시작하기

프로젝트를 시작하는 방법은 아주 간단해요.

### 개발 환경 실행

```bash
# 필요한 패키지들을 한꺼번에 설치해요
pnpm install

# 스토리북을 띄워서 컴포넌트를 확인해봐요
pnpm storybook

```

### 빌드

```bash
# 배포를 위해 모든 패키지를 빌드해요
pnpm build

# 배포용 스토리북을 빌드해요
pnpm build-storybook
```

## 📚 컴포넌트 둘러보기

왼쪽 사이드바에서 우리가 정성껏 만든 컴포넌트들을 만나보세요.

### UI Components

- **Button**: 다양한 스타일과 크기로 준비했어요. 상황에 맞는 버튼을 골라 사용해보세요.
- **Badge**: 정보를 한눈에 보여줄 때 유용한 배지 컴포넌트예요.

### Motion Components

- **FadeIn**: 화면에 요소가 부드럽게 나타나도록 도와줘요. 리듬감 있는 화면을 구성하고 싶을 때 유용해요.

## 🛠️ 기술 스택

완성도 높은 결과물을 위해 이런 도구들을 사용하고 있어요.

- **React 19**: 최신 버전의 React로 UI를 구축해요.
- **TypeScript**: 타입 안전성을 확보하여 실수를 줄여줘요.
- **Vite**: 빠르고 쾌적한 빌드 환경을 제공해요.
- **Vanilla Extract**: 타입 안전한 CSS-in-JS 방식으로 스타일을 관리해요.
- **Framer Motion**: 강력하고 유연한 애니메이션 기능을 활용해요.
- **pnpm**: 효율적인 패키지 관리를 도와줘요.
- **Storybook**: 컴포넌트들을 문서화하고 시각적으로 확인해요.

## 📖 사용 방법

각 컴포넌트 페이지에 들어가면 상세한 사용법을 확인할 수 있어요.
**Controls** 탭에서 옵션들을 직접 바꿔보며 컴포넌트가 어떻게 변하는지 확인해보세요!
